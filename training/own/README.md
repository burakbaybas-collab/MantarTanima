# Kendi fotoğraflarınız

Merkezde çekilen fotoğrafları buraya, tür kimliğiyle aynı adlı klasörlere koyun:

```
training/own/pleurotus_ostreatus/foto1.jpg
training/own/amanita_phalloides/foto2.jpg
```

Klasör adları `training/species.csv` içindeki `id` sütunuyla aynı olmalıdır.
Model yeniden eğitildiğinde bu fotoğraflar iNaturalist fotoğraflarıyla birlikte kullanılır.
